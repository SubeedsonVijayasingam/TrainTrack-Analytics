# TrainTrack – Learning Outcome Evaluation System

A learning outcome evaluation system designed to help companies measure the effectiveness of employee training programs and understand whether the skills learned during training are actually being applied in the workplace.

This mock UX demonstrates the application's primary screens, navigation flow, and major user journeys for HR/Admins, employees, and managers.

### Major User Journeys

**HR/Admin Journey**

Login → HR Dashboard → Create Training → Assign Employees → Monitor Training → View Analytics → Training Effectiveness Report

**Employee Journey**

Login → Employee Dashboard → View Training → Complete Training → Take Assessment → View Result → Submit Self-Evaluation

**Manager Journey**

Login → Manager Dashboard → View Employees → Select Employee → Review Training Performance → Evaluate Workplace Skill Application → Submit Feedback

### Key UX Flow

The system combines:

* Training participation and completion
* Assessment results
* Employee self-evaluation
* Manager evaluation
* Workplace skill application

These inputs are used to generate training effectiveness analytics and reports.

### Project Purpose

Companies often conduct employee training programs but have limited visibility into whether employees actually apply the acquired skills in their daily work. TrainTrack provides a structured way to collect training, assessment, self-evaluation, and manager feedback data so organizations can evaluate learning outcomes and training effectiveness.
